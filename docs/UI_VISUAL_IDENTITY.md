# Adaptix-native OpsGraph Visual Identity

The graph must not copy BloodHound icons, colors, or exact visual style. BloodHound is only conceptual inspiration for graph-based identity visualization.

## Direction

- Dark theme first.
- Soft motion.
- Clean vector glyphs.
- Minimal visual noise.
- Evidence-first side panel.
- Operator-friendly for long operations.

## Original node glyph categories

- User: soft identity glyph.
- Group: stacked identity glyph.
- Computer: workstation outline.
- Server: rack/server glyph.
- Domain: network boundary/globe glyph.
- Forest: larger boundary/container glyph.
- Trust: bridge/link glyph.
- Agent: Adaptix-style session pulse.
- Credential: key/secret glyph.
- Session: active context ring.
- Service: gear/process glyph.
- Share: network folder glyph.
- OU: tree/container glyph.
- IP/Subnet: network node glyph.
- Listener: signal/antenna glyph.

## Host state overlays

- Discovered: subtle outline.
- Enumerated: stronger outline.
- FootholdActive: active pulse badge.
- ElevatedFoothold: admin badge.
- ImpersonatedContext: context/mask badge.
- FootholdStale: dimmed stale badge.
- LostAccess: inactive badge.
